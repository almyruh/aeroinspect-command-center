# AeroInspect Command Center

Build a professional, modern SaaS web application called AeroInspect AI.

Purpose: An AI-powered aerospace component visual inspection dashboard that helps identify surface defects such as scratches, cracks, dents and corrosion.

Design requirements:

Premium aerospace engineering aesthetic.

Dark navy and charcoal background.

Subtle electric blue accents.

Clean typography and professional spacing.

Responsive desktop-first layout.

Dashboard features:

Sidebar navigation: Dashboard, New Inspection, Inspection History, Reports, Settings.

Overview cards: Total Inspections, Defects Detected, Components Passed, Components Failed.

A large image upload section with drag-and-drop functionality.

Inspection results panel showing defect categories, confidence scores and inspection status.

Image preview area with highlighted defect regions.

Recent inspection history table.

Use realistic sample data for the dashboard.

Important: This is a frontend prototype initially. Do not pretend that real AI defect detection is implemented yet. Use clearly labelled demonstration data.

Make the interface look like a professional aerospace technology product, not a generic AI template.
